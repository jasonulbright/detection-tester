# Keyboard

This page lists the keys that Detection Tester handles.

## What it does

The tool defines no shortcut of its own. It uses the standard keys of Windows controls.

## When to use it

Use it to work without the mouse.

## Requirements

None.

## Keys

| Key | Context | Effect |
|---|---|---|
| Tab, Shift+Tab | The window | Moves the focus forward or back. |
| Space or Enter | A button | Selects the button. |
| Space | A radio button or a check box | Selects it. |
| Esc | **Options**, a file dialog | Closes the dialog. |
| Up, Down | A list or a grid | Moves the selection. |
| Alt+F4 | The window | Closes the window and saves the window state. |

### Tab order of the Detection Tester page

1. The sidebar: **Detection Tester**, **Installed Applications**, **Options**.
2. **Detection Type**, **Import Stage Manifest...**, **Negative Test (Expect NOT Detected)**.
3. For RegistryKeyValue: **HKLM**, **HKCU**, **64-bit**, **32-bit (WOW6432Node)**, **Key Path**, **Value Name**, **Operator**, **Expected**.
4. **Test Detection**, then **Export CSV**, **Export HTML**, **Clear**.
5. The history grid, the log box and the theme toggle.

## Limits

- Each radio button is a Tab stop.
